# 配信スケジュール画像メーカー (StreamSchedule) 🗓️✨

> **実況配信者・VTuber向け 週間配信予定表・告知画像作成ツール**  
> テキスト入力とテーマ選択だけで、わずか3〜5分でプロ品質の高解像度告知画像（`1920x1080` / `1200x675`）を自動生成できるWebアプリケーションです。

---

## 🌟 主な特徴

1. **🔒 完全ブラウザ完結 (Client-Side Only)**
   - 画像合成やスケジュール情報はすべてブラウザ内（HTML5 Canvas 2D API & LocalStorage）で完結。未公開の企画や立ち絵画像が外部サーバーへ送信される心配はありません。
2. **🎨 4大デザインテーマ搭載**
   - **サイバーネオン (`cyber-neon`)**: ゲーミング・FPS・夜配信に映えるネオンシアン＆マゼンタ
   - **パステルポップ (`pastel-pop`)**: 雑談・歌枠・可愛い系VTuber向けのミルキーピンク＆ラベンダー
   - **シンプルモダン (`simple-modern`)**: どんな立ち絵にも合う洗練されたスレート＆インディゴ
   - **ダークシック (`dark-chic`)**: 落ち着いた大人っぽさを演出するチャコール＆シャンパンゴールド
3. **🖼️ 高精細 2解像度ワンクリック切替**
   - フルHD（`1920x1080`：OBS待機画面・YouTubeサムネイル兼用）と、Xタイムライン最適化（`1200x675`）を即座に切り替え可能。
4. **🧍 立ち絵・アバター透過合成**
   - ドラッグ＆ドロップで透過PNG立ち絵を読み込み、拡大縮小（0.5x〜2.0x）、X/Y位置調整、左右反転、透明度をリアルタイム調整。
5. **🚀 1クリック出力 & X (Twitter) 投稿連携**
   - 高解像度PNGダウンロード、クリップボードへの画像直接コピー（X画面で `Ctrl+V` ペースト可能）、告知文面＆ハッシュタグ自動生成付きの X Web Intent 投稿に対応。
6. **⏭️ 翌週への1クリック繰り越し**
   - 「次の週へ繰り越し (+7日)」ボタンで、定番の配信枠構成を残したまま日付だけを翌週へ一括更新。

## 🛠️ 起動・開発・検証コマンド

```bash
# 依存パッケージのインストール
npm install

# ローカル開発サーバーの起動 (http://localhost:5173)
npm run dev

# TypeScript 型チェック (エラー 0件)
npm run typecheck

# 単体・コンプライアンステスト実行 (Vitest: 全8スイート・90テスト合格)
npm test

# 本番用ビルド (dist/ 出力)
npm run build
```
