# 配信スケジュール画像メーカー (StreamSchedule) 🗓️✨

> **実況配信者・VTuber向け 週間配信予定表・告知画像作成ツール**  
> テキスト入力とテンプレート選択だけで、わずか3〜5分でプロ品質の高解像度告知画像（`1920x1080` / `1200x675`）を自動生成できるWebアプリケーションです。

---

## 🌟 主な特徴

1. **🔒 完全ブラウザ完結 (Client-Side Only)**
   - 画像合成やスケジュール情報はすべてブラウザ内（HTML5 Canvas 2D API & LocalStorage）で完結。未公開の企画や立ち絵画像が外部サーバーへ送信される心配はありません。
2. **🎨 8種類のビジュアルテンプレート ＆ カスタム背景画像アップロード**
   - 視覚的なミニチュアサムネイルから選べる8大デザインテンプレートを搭載：
     - **サイバーネオン (`cyber-neon`)**: ネオングリッド＆サイバーコーナー枠の近未来ゲーミング調
     - **パステルポップ (`pastel-pop`)**: ドット柄＆キラキラ星モチーフのかわいい癒し系
     - **シンプルモダン (`simple-modern`)**: どんな立ち絵にも合う洗練されたスタジオミニマル
     - **ダークシック (`dark-chic`)**: シャンパンゴールド二重額縁＆ダイヤ装飾の高級ゴシック
     - **和風・桜ノスタルジー (`sakura-wa`)**: 夜桜＆紅藤グラデーションに桜花びらと和モダン二重枠
     - **スターライト・ギャラクシー (`starlight-galaxy`)**: 深宇宙天の川グラデーションに星座ライン＆煌めく星屑
     - **カフェ・ナチュラルルーム (`cafe-natural`)**: ラテ＆モカブラウンにカフェボード風ステッチ枠
     - **ポップ・コミック Y2K (`pop-comic`)**: ビビッドイエロー＆シアンに太枠コミックライン
   - **手持ちのカスタム背景画像（BOOTH等の16:9背景素材・部屋背景）アップロード**にも対応し、背景の暗さ（0〜80%）やぼかし（0〜16px）を自在に調整可能。
3. **📐 3つの構図切替・フォント・推し色・すりガラス調整**
   - **構図切替**: `右立ち絵 (標準)` / `左立ち絵 (顔の向きに合わせられる)` / `立ち絵なしワイド` をワンクリック切替。
   - **フォント選択**: `テンプレ標準` / `スッキリ角ゴシック` / `かわいい丸ゴシック` / `クール明朝・セリフ` に対応。
   - **推し色（カスタムアクセントカラー）＆ カード不透明度（30%〜100%）**: 自分のイメージカラーや背景の透け感を自由に調整可能。
   - **配信プラットフォームバッジ & 推しマーク**: `YouTube`, `Twitch`, `TwitCasting`, `IRIAM`, `TikTok`, `17LIVE`, `ニコニコ` 等のバッジと推しマークをヘッダーに美しく描画。
4. **⚡ 毎週の制作を劇的に短縮する時短ツール**
   - **開始日からの7日間自動計算**: 「今週の月曜から」「来週の月曜から」「日曜始まり」「今日から7日間」やカレンダー指定で日付・曜日を一括セット。
   - **全曜日一括時刻セット**: お休み以外の全曜日の配信時刻を1クリックで一括変更。
   - **マイ定番枠（クイック入力タグ）**: よく行う配信（雑談・参加型・歌枠・コラボ等）を登録し、各曜日に1クリック挿入。
5. **💾 設定系の完全自動保存 & マイ設定プリセット・JSONバックアップ**
   - 配信者プロフィール・デザイン設定・**立ち絵画像（DataURL）＆配置設定**まで `LocalStorage` に完全自動保存。
   - **名前付きマイ設定プリセット**（複数保存・1クリック呼び出し）および **設定JSONファイルの書き出し/読み込み**に対応。
   - **スマートリセット**: 「予定枠のみクリア（設定・立ち絵は維持）」と「全設定を初期化」を分離し、毎週の更新時にマイ設定が消えない安心設計。
6. **🚀 1クリック出力 & X (Twitter) 投稿連携**
   - 高解像度PNGダウンロード、クリップボードへの画像直接コピー（X画面で `Ctrl+V` ペースト可能）、告知文面＆ハッシュタグ自動生成付きの X Web Intent 投稿に対応。

## 🛠️ 起動・開発・検証コマンド

```bash
# 依存パッケージのインストール
npm install

# ローカル開発サーバーの起動 (http://localhost:5173)
npm run dev

# TypeScript 型チェック (エラー 0件)
npm run typecheck

# 単体・コンプライアンステスト実行 (Vitest: 全8スイート・128テスト合格)
npm test

# 本番用ビルド (dist/ 出力)
npm run build
```
